Enum DecryptedMessage 

Source 
pub enum DecryptedMessage {
    Text(Text),
    Commit(Commit),
    Proposal(Proposal),
}
Expand description

Represents the potential items a consumer might require after passing us an encrypted message we have decrypted for him
