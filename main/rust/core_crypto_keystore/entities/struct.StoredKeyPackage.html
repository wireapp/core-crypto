Expand description

Entity representing a persisted KeyPackage

This entity cannot be updated in the DB: the primary key is the OpenMLS hash reference of the key package itself, so two rows sharing a key necessarily share their contents. A save which disagrees is a bug, and reports CryptoKeystoreError::AlreadyExists instead of silently replacing the stored key package.
